### 接口约定

### 数据（存在接口上，会同步）
- `api.method = 'MQTT'`；`api.url` 是 broker 地址：`mqtt://host:1883`、`mqtts://host:8883`、`ws://host:8083/mqtt`、`wss://...`，可带 `{{变量}}`。
- `api.extra.mqtt`（`dto.toApiMqtt` / `apiMqttOf`，读写都过它）：
```json
{
  "clientId": "apiloop-{{$randomInt}}",
  "username": "{{mqttUser}}", "password": "{{mqttPassword}}",
  "protocolVersion": 5,
  "clean": true, "keepalive": 60, "connectTimeoutMs": 10000,
  "will": { "topic": "", "payload": "", "qos": 0, "retain": false },
  "subscriptions": [ { "topic": "devices/+/status", "qos": 1, "enabled": true } ],
  "saved": [ { "name": "开灯", "topic": "devices/1/cmd", "payload": "{\"on\":true}", "qos": 1, "retain": false } ]
}
```
  `protocolVersion` 只有 3（3.1）、4（3.1.1）、5；`qos` 只有 0 / 1 / 2；`will.topic` 为空表示没有遗嘱消息。

### 会话（路由形状照 `/sio`）
- `POST /projects/:pid/mqtt`：请求体 `{ apiId?, environmentId?, url, clientId, username, password, protocolVersion, clean, keepalive, connectTimeoutMs, will, subscriptions }`，变量按 `/send` 同一套层级替换（含保密变量、`{{$guid}}` 这类），返回 `{ id: "mq_xxx", missing: [...] }`。
- `GET /mqtt/:id/events`：NDJSON，事件：
  - `{"type":"connecting","url":"mqtt://...","clientId":"..."}`、`{"type":"connected","sessionPresent":false}`
  - `{"type":"subscribed","topic":"devices/+/status","qos":1,"granted":1}`（broker 拒绝时 `granted` 是 128 / 原因码，带中文 `error`）、`{"type":"unsubscribed","topic":"..."}`
  - `{"type":"message","topic":"devices/1/status","payload":"文本","payloadBase64":null,"qos":1,"retain":false,"properties":{...},"at":...}`（payload 是合法 UTF-8 就给文本，否则给 `payloadBase64`）
  - `{"type":"published","topic","payload","qos","retain","at"}`（自己发出的，QoS 1/2 要等 broker 确认后才发这一行）
  - `{"type":"reconnecting"}`、`{"type":"closed"}`、`{"type":"error","error":"中文"}`
  事件先缓存，页面晚连 / 重连时从头补发（照 sio）。
- `POST /mqtt/:id/subscribe` `{ topic, qos }`、`POST /mqtt/:id/unsubscribe` `{ topic }`。
- `POST /mqtt/:id/publish` `{ topic, payload, qos, retain }`（payload 文本可带 `{{变量}}`，按建会话时的环境替换）；主题里带 `+` / `#` 返回 400「发布的主题不能带通配符」。
- `DELETE /mqtt/:id`：断开并删掉会话。
- 只有创建者能访问，别人一律 404；空闲回收、每人会话数上限照 sio。
- 常见错误给中文：连不上（ECONNREFUSED / 超时）「连不上 broker，检查地址和端口」、认证失败（CONNACK 4 / 5、v5 的 134 / 135）「用户名或密码不对 / 没有权限」、clientId 被占用被踢「同一个 clientId 在别处登录，被 broker 断开」、TLS 证书问题。
- 系统代理不作用于 MQTT，和 sio 一样在 `connecting` 里带 `note`。

### 其他地方对 MQTT 的处理（和 SIO / GRPC 一致）
