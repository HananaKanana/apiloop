# 2.1.0 验收清单

第三轮到第九轮的 27 个新功能，按「先网页版、再客户端」排。每条是「怎么做 → 应该看到什么」。
发现问题记下是哪一条、怎么操作的、看到了什么，交给主会话。

## 准备

1. 服务器：`git pull && ./deploy.sh up --cn`，升到最新代码（云端此时还显示 2.0.3，正常 —— 版本号等正式发版时才改）。
2. 客户端：装 `agent-installer/dist/leonaz.top/` 里 **2.1.0** 的测试包（Mac 选 arm64 / x64，Windows 选 exe）。
   Windows 上现在装的版本一键更新有问题，**这次手动下载安装**。
3. 准备两个账号：你自己（管理员）+ 一个普通成员（在测试项目里分别设成 editor、viewer 各试一次）。
4. 准备一个测试项目，里面有几个目录、十来个接口，其中一个是「登录」接口（响应里有 token）。

## 一、网页版就能测（浏览器打开 http://leonaz.top:8765）

### 1. 回收站
- [ ] 删一个接口 → 左侧栏底部「回收站」有条数；打开能看到它，「恢复」后回到原目录，示例、Mock 都还在。
- [ ] 删一个带子目录的目录（选「连同接口一起删」）→ 恢复后整棵树回来，顺序和删之前一样。
- [ ] 删一个环境 → 回收站里有，能恢复。
- [ ] 「彻底删除」「清空回收站」有确认框，确认后没了。
- [ ] viewer 账号能看到回收站列表，没有「恢复」「彻底删除」按钮。

### 2. 批量运行
- [ ] 目录右键「运行」→ 打开运行标签页，列表顺序和目录树一致，WebSocket 接口不在里面。
- [ ] 登录接口用脚本或「断言」页签提取 token，后面的接口用 `{{token}}` → 批量跑能串起来。
- [ ] 有断言失败的那一行标红，「只看失败」能筛出来，点开看到原因。
- [ ] 次数设 3 → 每个接口跑 3 遍；跑到一半点「停止」能停。
- [ ] 默认不勾「记到历史里」→ 历史没有新增；勾上 → 有。
- [ ] 跑的时候切到别的标签页再切回来，运行没断。

### 3. 保密变量
- [ ] 环境里加 `password`，点眼睛设成保密，填值 → 发请求能用上。
- [ ] 另一个账号看到 `password` 这个变量，值是空的。
- [ ] 导出环境 JSON → 里面 `password` 的值是空的。
- [ ] 历史记录里这次请求，保密值显示成 `******`。
- [ ] 升级前就标过保密的变量，升级后照常能用。

### 4. 接口文档分享 + 我的分享
- [ ] 目录右键「分享文档」→ 生成链接 →「复制」不报错 → 无痕窗口打开，不用登录，左边有目录树、右边有文档。
- [ ] 目录树空白处右键「分享整个项目的文档」→ 打开后左边是整个项目的树。
- [ ] 文档里看不到：环境变量的值、Authorization 的值、脚本；登录接口示例里的 token 显示成 `******`。
- [ ] 文档页的 Mock 地址复制出来能直接调通。
- [ ] 头像菜单「我的分享」→ 能看到所有项目的链接；撤销后再打开链接显示「已失效」。
- [ ] viewer 账号在「我的分享」里看不到「撤销」。

### 5. 接口状态和负责人
- [ ] 接口设「开发中」、负责人选自己 → 保存后目录树上有橙点，悬停能看到状态和负责人。
- [ ] 设「已废弃」→ 目录树里名字灰色加删除线。
- [ ] 筛选「我负责的」→ 只剩自己负责的接口。
- [ ] 分享文档里能看到状态和负责人名字。

### 6. 导出 OpenAPI
- [ ] 项目名下拉「导出为 OpenAPI」，YAML → 用 https://editor.swagger.io 打开不报错，接口、参数、示例都在。
- [ ] 导出的文件再用 OpenAPI 导入导进一个新项目 → 接口数量、地址、参数对得上，目录分组还在。
- [ ] 目录右键导出 → 只包含这个目录下的接口。

### 7. 从 OpenAPI 同步更新（需要一个真实的 Swagger 地址）
- [ ] 从 Swagger 地址导入 → 在某个接口里写脚本、存示例、自己加一个请求头。
- [ ] 后端改接口（加参数、删一个接口、加一个接口）→ 目录树空白处右键「从 OpenAPI 同步更新」→ 新增 / 有改动 / 已删除三组都列出来。
- [ ] 同步后：新参数出现了；脚本、示例、自己加的请求头都还在；「已删除」那组默认不勾，勾了的进回收站。
- [ ] 再检查一次 →「已经是最新的」。
- [ ] 这个功能之前就导入过的老项目也能同步（不会整批当成新增）。

### 8. 公共请求头
- [ ] 目录设置里加公共请求头 `X-Test: 1` → 这个目录下的接口发送时带上了（在响应面板「请求」里看实际发出的头）。
- [ ] 接口的 Headers 页签下面灰色显示继承来的请求头和来源；接口自己加同名的 → 继承的那行划掉，发出去的是接口自己的值。
- [ ] 「在这里覆盖」把那一行复制到接口自己的表里。
- [ ] 项目设置里也能加，作用于整个项目。
- [ ] 「复制为 cURL」里也带着公共请求头。

### 9. 全局查找替换
- [ ] `⌘⇧F`（Windows `Ctrl+Shift+F`）或项目名下拉「查找替换」打开 → 输入地址里的一段，结果按接口分组、高亮。
- [ ] 替换框填新值，勾掉一两处 →「替换所选」→ 只改了勾选的那些，目录树和打开的标签页刷新。
- [ ] 一个接口打开着、有未保存的修改 → 替换时它被跳过，结果里有提示。
- [ ] 开「正则」写个错的正则 → 提示「正则写得不对」，不卡死。
- [ ] viewer 账号只能查找，没有替换。

### 10. 环境对比
- [ ] 环境下拉最下面「对比所有环境」→ 一张表，缺的格子灰色「（缺少）」，各环境都一样的值是浅灰。
- [ ] 直接在格子里改 → 标黄 →「保存」后各环境都更新了。
- [ ] 「补齐缺少的变量」→ 缺的都加上（空值），填好保存。
- [ ] 有未保存的修改时关标签页 → 要确认。

### 11. 接口评论和 @ 提醒
- [ ] 接口右上角「评论」→ 右侧滑出面板，发一条（`⌘/Ctrl + Enter`）。
- [ ] 输入 `@` 弹出成员，选另一个账号 → 对方右上角铃铛有红点，点那条提醒直接打开这个接口、展开评论。
- [ ] 评论里写一个网址能点开；写 `<b>测试</b>` 原样显示成文字，不会变粗体。
- [ ] 自己的评论能编辑、删除，删除后显示「这条评论已删除」。
- [ ] viewer 账号也能评论。

### 12. 可视化断言和提取变量
- [ ] 接口「断言」页签：一键添加「状态码是 200」「响应时间 < 1000ms」「code 等于 0」→ 发送后「测试结果」里显示通过。
- [ ] 改一个断言让它失败 → 显示没通过和原因。
- [ ] 响应 JSON 里在 `token` 上右键「提取为变量」→ 断言页签里多了一行 → 保存、发送 → 环境里有了 token，后面的接口能用。
- [ ] 在某个字段上右键「为这个字段加断言」→ 加了一行「等于 当前值」。
- [ ] 选内置 Mock 环境时提取到环境 → 有提示「没有选环境，这个变量没有保存」。

### 13. 响应字段说明
- [ ] 接口「响应说明」页签「从示例生成」→ 列出所有字段（数组写成 `list[]`），填几个说明，保存。
- [ ] 重新「从示例生成」→ 写过的说明还在。
- [ ] 分享文档里示例下面有「响应字段」表格；导出 OpenAPI 里属性带着说明。

### 14. 跨项目复制 / 移动
- [ ] 接口右键「复制到其他项目…」→ 选项目、目录 → 目标项目里出现了，示例、脚本、Mock 都在；「去看看」能跳过去。
- [ ] 目录「移动到其他项目…」→ 整棵树过去了，原项目里的进了回收站。
- [ ] 项目名下拉「复制为新项目…」→ 新项目里目录、接口、环境、公共请求头都在；成员只有你自己；保密变量只有名字没有值。

### 14a. Mock 故障模拟（第七轮，不在已打的 2.1.0 测试包里，网页版测）
- [ ] 项目设置开「故障模拟」，点预设「不稳定」→ 多调几次 Mock，大约每 10 次有 1 次返回 500；Mock 日志里那条有「故障」标签。
- [ ] 预设「弱网」→ 请求明显变慢。
- [ ] 加「断开连接」100% → 调用方看到网络错误；「超时」→ 一直等到设定时间后断开。
- [ ] 作用范围选一个目录 → 只有这个目录（含子目录）下的接口受影响。
- [ ] 请求带头 `X-Apiloop-Fault: off` → 不受影响。
- [ ] 开着时项目名旁边有「故障模拟中」，关掉后消失。

### 14b. 项目分组和收藏（第七轮）
- [ ] 项目下拉能搜索；项目悬停点星标收藏 → 排到最上面。
- [ ] 「管理分组」建两个分组、把项目放进去 → 下拉里按分组显示，能折叠。
- [ ] 接口右键「收藏」→ 目录树最上面出现「收藏」区，点了能打开。
- [ ] `⌘K` / `Ctrl+K` 不输入时列出最近打开的接口，跨项目点了能切过去。
- [ ] 另一台设备（或网页版）登录同一账号 → 分组和收藏一样；另一个账号看不到你的分组和收藏。

### 14c. GraphQL 自动补全（第七轮，需要一个 GraphQL 接口）
- [ ] Body 选 GraphQL →「获取 Schema」→ 显示「已加载（N 个类型）」。
- [ ] 写查询时字段自动补全，写错的字段标红，悬停看说明。
- [ ] 打开「文档」面板，能从 Query 一层层点进去看类型和字段。
- [ ] 对一个不是 GraphQL 的地址获取 Schema → 显示能看懂的失败原因。

## 二、要装 2.1.0 客户端才能测

### 15. 保密值在自己的设备之间同步
- [ ] 网页版给某个变量设保密、填值 → 客户端（同一账号）里过一会儿能看到这个值。
- [ ] 客户端里改这个值 → 网页版刷新后是新值。
- [ ] 关掉保密 → 另一端也不再是保密。
- [ ] 另一个账号始终看不到这个值。
- [ ] 客户端断网时改了保密值 → 联网后另一端能看到。

### 16. 回收站跨设备
- [ ] 两台客户端登录同一个账号：A 删一个接口，B 的回收站里能看到并能恢复；恢复后 A 那边也出现。

### 17. 客户端里的云端功能
- [ ] 客户端里分享、我的分享、评论、提醒都能用（请求会转给云端）。
- [ ] 客户端退出登录 → 分享、评论、铃铛、我的分享都不显示。
- [ ] 弹窗里的「复制」按钮都能用（分享链接、Mock 地址）。

### 17a. 测试集（第八轮，要客户端运行；网页版能编辑、看记录）
- [ ] 左侧栏切到「测试集」→ 新建一个 →「添加接口」从两个不同目录勾几个接口（勾目录 = 加整个目录）→ 能拖动排序。
- [ ] 登录接口在「断言」页签里提取 token，后面的接口用 `{{token}}` → 运行 → 全部通过；把登录接口的断言改成会失败的 → 报告里那一步标红、写着原因。
- [ ] 某一步「失败时」选「跳过本轮剩下的」→ 它失败后，这一轮后面的步骤显示「跳过」。
- [ ] 跑完后去环境里看：`token` **没有**被改成运行时提取的值（只在这次运行里有效）。
- [ ] 「数据」页签粘一份 CSV（3 行，列名 `user`）→ 预览出 3 行、写着「会跑 3 轮」；接口里写 `{{user}}` → 跑 3 轮，报告按轮分组，每轮标题有这一轮的数据。
- [ ] CSV 故意写错（引号不配对）→ 提示哪一行错了。
- [ ] 跑一个慢的测试集，中途点「停止」→ 很快停下，状态「停止」，运行记录里有这一条。
- [ ] 「运行记录」页签：能看到每次运行（时间、环境、结果、通过数、用时），点开是报告；「导出报告」下载的 HTML 双击能打开、内容完整。
- [ ] 同事登录另一个账号 → 在同一个项目里能看到这个测试集和它的运行记录。
- [ ] 批量运行标签页「存为测试集」→ 新测试集里就是勾选的那些接口、顺序一样。
- [ ] 网页版点「运行」→ 提示「网页版不能运行测试集，请在客户端里运行」。
- [ ] 客户端退出登录（只用本机）→ 测试集照样能跑，「运行记录」页签提示登录后才保存。

### 17b. 压测（第八轮，只在客户端）
- [ ] 接口「发送」旁的下拉 →「压测…」→ 打开压测标签页；并发 10、按次数 500 → 开始 → 数字实时跳、曲线每秒一个点 → 结束后有 P50 / P90 / P95 / P99、状态码分布。
- [ ] 按时长 30 秒，跑到 10 秒点「停止」→ 很快停下，**照样显示到这一刻为止的汇总**。
- [ ] 压一个会返回 500 的地址 → 失败数、状态码分布里 `500 × N`；压一个连不上的地址 → 错误分组里「连接被拒绝」。
- [ ] 环境名里带「生产」或「prod」→ 开始前弹红色确认框。
- [ ] 「复制结果」贴到聊天框里是一段能看懂的文字；再跑一次，「上次结果」留在下面。
- [ ] 并发填 500 → 提示范围（最多 200）。
- [ ] 网页版：下拉里的「压测…」是灰的，悬停有说明。
- [ ] 压测时切到别的标签页再切回来，压测没断。

### 14d. YApi / Apifox 导入（第九轮，网页版就能测）
- [ ] 在 YApi 项目里「数据导出 → json」→ apiloop 导入弹窗选「YApi」→ 预览显示几个目录、几个接口 → 导入后目录、接口、参数说明、必填、状态都对。
- [ ] YApi 里写了 JSON Schema 请求体的接口 → 导入后请求体是普通示例值（不是 `{{@…}}`），能直接发。
- [ ] 响应示例变成了 Mock 返回，「响应说明」页签里有字段说明。
- [ ] Apifox「导出 → Apifox 格式」→ 选「Apifox」导入 → 接口、环境都建出来；**这一种没有真文件验过**，哪里不对把提示截图给主会话。
- [ ] 一个 10 MB 以上的导出文件也能导入（以前 4 MB 就被拒）。

### 14e. 导出文档（第九轮）
- [ ] 项目名下拉「导出文档…」→ Markdown / HTML / Word 各导一次 → 都能打开；HTML 左边目录能点跳转；Word 打开时提示更新域，更新后目录有页码。
- [ ] 目录右键「导出文档…」→ 只有这个目录下的接口。
- [ ] 文档里：必填一列有「是」；示例响应是正常数据（不是 `{{@word}}` 这种模板）；token、密码是 `******`。

### 17c. 数据库操作（第九轮，只在客户端执行）
- [ ] 项目设置「数据库连接」加一个 MySQL（主机、密码用 `{{变量}}`）→「测试连接」成功；故意填错密码 → 提示写清原因。
- [ ] 接口「数据库」页签：请求前 `INSERT …`，提取 `[0].insertId` 存成 `uid`；请求地址里用 `{{uid}}` → 发送 → 控制台里有插入那一行，请求带上了新 id。
- [ ] 响应后 `SELECT … WHERE id = {{uid}}`，提取字段 → 断言里用这个变量 → 通过；控制台贴出了查到的前几行。
- [ ] 请求前的语句写错 → 请求没发出去，提示是哪条语句、为什么错。
- [ ] 查一个 BIGINT 的大 id（雪花 ID）→ 提取出来的值末几位没变。
- [ ] Redis：`GET key` 提取整个返回值。
- [ ] 测试集里跑带数据库操作的接口 → 照常执行。
- [ ] 网页版发送带数据库操作的接口 → 控制台提示「只在客户端里执行，这次跳过了」。

### 17d. Socket.IO 调试（第九轮，只在客户端）
- [ ] 目录树「＋」→「Socket.IO」→ 填地址、命名空间，auth 填 `{"token": "{{token}}"}` → 连接 → 服务端收到的 auth 里是替换后的值。
- [ ] 发事件（多个参数、勾「等待确认」）→ 消息列表里有发出、确认回包、服务端推过来的事件。
- [ ] 保存接口后关掉再打开 → 地址、auth、监听事件、常用发送都还在。
- [ ] 连一个不是 Socket.IO 的地址 → 提示「对方可能不是 Socket.IO 服务端……」。

### 18. 一键更新（正式发版时测）
测试包是 2.1.0。测完修的问题打进正式版时，版本号用 **2.1.1**（比测试包高），云端升级后客户端会提示更新，正好测一键更新：
- [ ] Windows 客户端点「更新」→ 程序关掉、自动装好、重新打开，不再报「文件被另一个程序使用」。
- [ ] Mac 客户端点「更新」→ 弹出系统安装程序，输密码装好后自动重新打开。
