**目标**：在管理台能看到最近有哪些请求打到了 mock，每条请求命中了哪个接口、哪条期望，或者根本没有命中。

**架构**：
- 新增 `lib/mock-log.js`，用内存环形缓冲按项目保存日志，每个项目最多 200 条。
- 由 `mock-runtime` 负责记录「匹配到的请求」，由 `mock-host` 负责记录「`/mock/<slug>` 下没有匹配到的请求」。
- 日志通过 `lib/api/mock-log.js` 暴露给管理台，两条路由都要挂 guard。

**依据**：接口契约 [docs/design/2026-09-30-admin-api-v2.md](../../design/2026-09-30-admin-api-v2.md) 第 11 节。

## 全局约束

- **文件范围**：`lib/**`（不含 `lib/web`）、`README.md`。
- **记录日志绝不能影响 mock 响应本身。** 记录逻辑整体包在 try/catch 里，出错只 `console.warn` 一次。截取响应内容也不能改变发给客户端的数据。
- **只截取前 4KB**，不要把整个请求体、响应体都存进内存。

## 审阅重点

1. **大响应不占内存**：一个 5MB 的 mock 响应，日志里只留 4KB 的预览，内存占用不能随响应体大小增长。
2. **带延迟的接口，耗时要准确**：设置了 `delay` 的接口，`durationMs` 必须包含这段延迟，所以要在响应的 `finish` 事件里计时，不能在调用 handler 时就算。
3. **凭据打码**：日志里 `Authorization` 和 `Cookie` 的值只能是 `***`。头名匹配不区分大小写。
4. **按项目隔离**：A 项目的成员通过 `GET` 拿不到 B 项目的日志。

### Task 1: `lib/mock-log.js`

**接口**：
- `record(projectId, item)`：由模块自己分配 `seq` 和 `time`，并对请求头打码。
- `list(projectId, { after, limit }) -> { items, lastSeq }`：`limit` 默认 100，最大 200。
- `clear(projectId)`
- `forget(projectId)`：删除项目时调用。

- [ ] **Step 1**：用 `Map<projectId, item[]>` 存储，超过 200 条就从头部丢弃。`seq` 是模块级的计数器。
- [ ] **Step 2**：提交：`feat: mock 调用日志的内存存储`

### Task 2: 在请求链路里接入记录

**文件**：修改 `lib/mock-runtime.js`（`createHandler` 需要拿到 projectId，所以 `createRuntime(store)` 要把 `store.projectId` 传下去）、修改 `lib/mock-host.js`。

- [ ] **Step 1：记录匹配到的请求**
  - 在 `createHandler` 一开始记下开始时间。
  - 请求体预览从 `req.body` 取：是对象就 `JSON.stringify` 后截取；是字符串就直接截取。
  - 在 `send` 里调用 `res.send(text)` 之前，先把响应内容截取 4KB 存下来。
  - 在 `res.on('finish')` 里调用 `mockLog.record`，`matched` 字段按契约填写，其中 `via` 和 `expectationName` 来自 `matchExpectation` 的结果。
- [ ] **Step 2：记录没有匹配到的请求**
  - 在 `mock-host` 的 `dispatch` 里，只处理带 `/mock/<slug>` 前缀的请求：runtime 调用 `next`（表示没有匹配）时，先在 `res` 上挂一次性的 `finish` 监听，里面用 `matched: null`、`res.statusCode`、空的 `responsePreview` 记录一条日志，然后再调用外层的 `next`。
  - 根项目的请求不在这里记录。
- [ ] **Step 3：自测**
  - 命中默认示例、命中期望、`/mock/<slug>/不存在` 三种情况各打一次，分别检查日志里的 `matched` 和 `status`。
  - 设置 `delay: 300` 的接口，`durationMs` 应该 ≥ 300。
  - 用 5MB 的响应体测试，日志里的 `responsePreview` 长度不超过 4KB。
  - 带 `authorization` 请求头发请求，日志里的值是 `***`。
- [ ] **Step 4**：`npm test` 全部通过后提交：`feat: mock 请求链路接入调用日志`
