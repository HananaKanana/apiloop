## 全局约束（视觉规范，所有 Task 都按这个来）

- **间距**：内容区统一使用 `12px 16px` 的内边距；页签条左边留出 16px；表格行高 32px；目录树行高 28px。
- **字号**：界面正文 13px；表头和辅助说明 12px，使用 `opacity: 0.6`；代码和响应体用等宽字体，12px。
- **请求方法的颜色**：新建 `web/src/utils/method.js`，导出 `methodColor(method)`，**全站只用这一份**。目录树的方法标签、地址栏的方法下拉、顶部标签页的标题，都从这里取颜色。

  | 方法 | 颜色 |
  | --- | --- |
  | GET | `#0cbb52` |
  | POST | `#ffb400` |
  | PUT | `#097bed` |
  | PATCH | `#623ce4` |
  | DELETE | `#eb2013` |
  | HEAD / OPTIONS | `#6b7280` |
  | WS | `#0ea5a4` |
  | 其他 | `#6b7280` |

  方法标签的样式：只有文字颜色，没有边框和底色；粗体，10–11px；宽度固定 44px，右对齐。这样各行的接口名能对齐。
- **主色**（2026-09-30 用户选定 **Postman 橙**，已经由审阅方改好）：
  - naive-ui 的 `themeOverrides` 主色：亮色主题 `#ff6c37`，暗色主题 `#ff7a4d`；
  - naive-ui 组件之外的自定义样式，**一律用 `var(--apiloop-primary)`**，这个变量在 `App.vue` 里定义；
  - **不要再写 `var(--n-primary-color, #…)`**：这个变量在 naive-ui 组件外面取不到，最后只会用上后面写死的那个颜色。
- **变量的颜色**（配合橙色主色调整过，已经在 `VarInput` 里改好）：
  - `{{已定义}}`：蓝色 `#1d4ed8`，暗色主题下用 `#93c5fd`；
  - `{{未定义}}`：红色 `#dc2626`，暗色主题下用 `#fca5a5`；
  - `{{@mock 占位符}}`：紫色 `#7c3aed`，暗色主题下用 `#c4b5fd`；
  - 都带一层 10% 透明度的同色底，并加 2px 圆角。

  已定义变量不能再用绿色（和 GET 撞色），也不能用橙色（和主色、POST 撞色）。
- **状态码的颜色**：2xx 绿色、3xx 蓝色、4xx 橙色、5xx 红色、出错灰色。
- **暗色主题**：所有新加的颜色都要在暗色主题下检查可读性。暗色下使用对应的亮一些的色号，不能写死一个只在白底上好看的颜色。

## 审阅重点

1. **变量高亮和补全不能影响输入**：
   - 换成 CodeMirror 之后，地址栏必须是单行的：粘贴带换行的内容时，换行要被去掉；
   - 回车就是发送；**补全列表打开时，回车用来选中补全项，不发送**；
   - 光标、选中、撤销都正常；
   - 中文输入法组字的过程中，不能打断，也不能触发发送或补全。
2. **变量的解析和后端一致**：前端判断变量「已定义」时，优先级是「项目 < 目录（从外到内）< 环境」，和契约第 5 节相同。悬停提示和补全列表里显示值和来源，`secret` 变量的值要遮住。
3. **性能**：一个表格里有几十行参数时，编辑不能卡顿。可以只给「正在编辑、或者包含 `{{` 的格子」挂 CodeMirror，其余格子仍然用普通输入框；具体怎么做由你决定，但要满足这一条。
4. **只读角色**：viewer 下，这些新组件同样是只读的，也不弹出补全。

### Task 2：`{{变量}}` 高亮、补全与悬停提示

- [ ] 新建 `web/src/utils/variables.js`，导出下面两个函数：

- [ ] 新建 `web/src/components/common/VarInput.vue`：单行的 CodeMirror 6 编辑器。
  - **外观**：和 naive-ui 的小号输入框保持一致，高度、边框、圆角、聚焦时的颜色都一样。
  - **高亮**：用 decoration 给变量上色，颜色按全局约束。

    - 选中之后补全成 `{{name}}`；如果光标后面已经有 `}}`，就不要再补一对；
    - 列表按「环境 → 目录 → 项目」排序，也就是优先显示生效的那个；同名变量只列出生效的那一个；
    - 在 mock 示例编辑器（`CodeEditor`）里，输入 `{{@` 时补全 mock 占位符，数据来自 `/meta` 的 `placeholders`，每一项显示占位符的名字和说明。请求区不补全 mock 占位符，因为发送请求时不会渲染它们。
  - **悬停提示**：鼠标移到变量上时显示提示。已定义的，显示「值（secret 遮住）· 来源」；未定义的，显示「未定义 —— 在环境、目录或项目变量里添加」。
  - **单行**：通过 transactionFilter 把换行去掉。补全列表没打开时按回车，触发 `enter` 事件交给父组件处理；中文输入法组字过程中按回车，不触发这个事件。
  - **属性**：`modelValue`、`placeholder`、`readonly`、`scope`（也就是 `resolveScope` 的结果）。
- [ ] **使用的地方**：

  - 参数、请求头、表单这三类键值表格的「值」这一列，「键」这一列可以不用，性能要求见审阅重点第 3 条；
  - 鉴权里的 token、用户名、密码、key、value；
  - WebSocket 标签页的地址栏。
- [ ] **未定义变量的提示移到请求区**：现在响应区里那条「以下变量未定义」，移到地址栏的正下方，改成一行紧凑的黄色提示。发送之前就要显示，用 `findVariables` 和 `scope` 在前端直接算出来，不用等发送之后。提示里保留「去环境管理」这个入口。响应区里的这条提示删掉。

### Task 6（用户追加，排在 Task 5 后半之后）：表格式输入，按 Postman 的样式改

**依据**：用户对比了 Postman 的 form-data 表格截图。Postman 的参数表是**一整张网格表**：单元格之间用 1px 的细线分隔，格子里的输入框**本身没有边框、没有底色**，看起来就是直接在表格上打字。我们现在是每一格一个独立带边框的输入框，一行三个框排在一起，显得又重又碎。

**样式规范**（全站所有「键值类」的表格都统一）：
- 整张表带 1px 的外框，行和行之间、列和列之间都有 1px 的分隔线，颜色用 naive-ui 的 border 色，外框加 4px 圆角。
- **表头**：一行，12px，灰色，列之间有竖线，内边距 `6px 8px`，底色略深一点：亮色用 `rgba(0,0,0,0.02)`，暗色用对应的浅色透明值。
- **单元格里的输入框**：没有边框，底色透明，内边距 `6px 8px`，行高 32px。
  - 聚焦时，只在**这个格子里**显示一层很浅的主色底，或者 1px 的内描边，不能撑开布局；
  - 占位文字是灰色的「Key」「Value」「描述」，按现在的中文界面，写成「参数名 / 值 / 描述」。
- **勾选框那一列**宽 32px，居中显示。末尾的占位行没有勾选框（沿用之前的规则）。
- **行悬停**时，整行显示浅灰底，最右边出现删除图标，删除图标的位置固定，不能挤压列宽。
- **停用的行**，文字半透明。
- **描述列默认隐藏**，和 Postman 一样。表格右上角的「…」菜单里提供「显示描述列」；如果某一行已经填了描述，就默认显示这一列。显示与否按表格类型记进 `localStorage`，读写要包在 try/catch 里。
- **类型下拉**（form-data 的「文本 / 文件」、变量表的「保密」开关这类）：放在格子里，同样没有边框，参考 Postman 的「File ▾」「Text ▾」。选择文件之后，在格子里显示「文件图标 + 文件名」这样一个小标签。

**`VarInput` 增加一个 `bare` 属性**：去掉边框和底色，专门在表格格子里用。聚焦时的效果按上面的规则来。

最后这一条是 Task 6 留下的 bug，见审阅文档第 5 轮。

**先修 bug：去边框的写法在 4 处没有生效**
- **原因**：naive-ui 把 `--n-border`、`--n-color` 这些 CSS 变量写在组件的**内联样式**上。在样式表里用 `.cell :deep(.n-input) { --n-border: none }` 覆盖，优先级比内联样式低，所以不生效。你自己在 ad6c7bd 的提交说明里也写过「类选择器盖不住」。
- **涉及的 4 处**：`VarTable.vue`、`BodyEditor.vue`、`UrlBar.vue`、`VarInput.vue`，搜索 `--n-border: none` 就能找到。
- **修法**：统一改成给组件传 `:theme-overrides`，例如 `n-input` 传 `{ border: 'none', borderHover: 'none', borderFocus: 'none', boxShadowFocus: 'none', color: 'transparent', colorFocus: 'transparent', paddingSmall: '0' }`，`n-select` 同理。把这份配置放在 `web/src/utils/bareInput.js` 里共用。**不要用 `!important`**。
- **`VarTable` 的空行**：「启用」和「保密」两个勾选框都加上 `v-if="!row.__draft"`，和 `KeyValueTable` 保持一致。
