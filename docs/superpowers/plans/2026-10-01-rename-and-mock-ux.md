## 全局约定

- 不写新测试，`npm test`（71 个）必须全过。界面行为由用户确认，回报里写清楚改了哪些地方、用户该怎么点。
- 用户看得到的文字一律中文。
- 不改后端。

## 审阅重点

1. **改名不能连带保存别的修改，也不能弄脏标签页。** 标签页里有没保存的请求修改时双击改名：只有名字保存了，其他修改还是「未保存」；保存过的地方（`tab.api.name`、快照里的名字）跟着改，改完不会凭空多出一个「未保存」的点。
2. **Esc、清空、重名、失败：** Esc 取消；清空或者只有空格就恢复原名，不发请求；保存失败时提示错误，并恢复原名。
3. **Mock 页的三步状态都是现算的。** 新建、删除示例，开关 mock 之后，打勾和状态文字马上跟着变，不用刷新。
4. **「用最近一次响应生成」复用响应区现有的「保存为示例」流程**（`RequestTab.vue` 里的那个弹窗），不要再写一套。
5. **只读成员（viewer）看不到任何写入口**，和现在一样。

### Task 1：双击改名

**文件：** `web/src/components/request/RequestTab.vue`、`web/src/components/ws/WsTab.vue`、`web/src/components/folder/FolderTab.vue`，必要时 `web/src/stores/tabs.js`（加一个只改名字的方法）

**做什么：**
- 面包屑最后一段（接口名、目录名）：
  - 鼠标移上去有浅色底，`title="双击重命名"`；
  - 双击变成同样字号的输入框，文字全选。
- **回车或失焦**提交，**Esc** 取消。去掉首尾空格后为空，或者和原名一样，就直接退出编辑，不发请求。
- **已保存的接口：** 调 `tree.renameApi(id, name)`，成功后：
  - 标签页标题、`tab.api.name` 都换成新名字；
  - 保存快照里如果有名字，也换成新名字，保证 `dirty` 不因为改名变化（审阅重点 1）；
  - 不调 `markSaved`，它会把整个 spec 换掉。
- **目录：** 调 `tree.renameFolder(id, name)`，目录标签页的标题跟着变。
- **还没保存过的新请求（没有 `apiId`）：** 只改 `tab.title`，保存时弹窗里的默认名用它。
- 失败：`message.error(原因)`，名字恢复原样。
- 只读成员不能改：不显示浅色底，双击也没反应。
- 目录树的双击行为**不动**（现在是把预览标签页固定住）。

**回报：** 写清楚四种情况：
1. 改一个已保存的接口名，目录树和标签页标题都变了；
2. 改名前先改一下请求地址，改完名后地址的修改仍然是「未保存」；
3. 新请求改名后点保存，弹窗里的默认名是新名字；
4. Esc 和清空都会恢复原名。

### Task 2：Mock 页重新组织

**文件：** `web/src/components/mock/MockPanel.vue`，必要时 `web/src/components/request/RequestTab.vue`（把「保存为示例」的入口暴露给 Mock 页）

**页面从上到下：**

1. **一句话说明**（灰色小字，常驻）：「Mock 就是『假接口』：后端还没写好时，先请求下面的 mock 地址，拿到你在这里设定的假数据。」
2. **三步**，每步左边一个圆圈序号，做完了换成绿色的勾：
   - **① 准备返回的数据**
     - 有示例：「已有 N 个示例」；
     - 没有示例：两个按钮「新建示例」和「用最近一次响应生成」。后一个只在这个标签页有响应时显示，点了走现有的「保存为示例」弹窗（审阅重点 4）。
   - **② 打开 mock**：现在的开关挪到这里，旁边写当前效果：
     - 没开：「未开启：请求 mock 地址会返回 404」；
     - 开了、没有示例：先实际请求一次看返回什么，再如实写；
     - 开了、有示例：「已开启：会返回示例『<默认示例名>』」。有期望时再补一句「满足条件时按『按条件返回』里的规则」。
   - **③ 调用 mock 地址**：mock 地址加一个「复制」按钮。下面一行小字：「或者在右上角环境里选『Mock』，直接点『发送』」。
     - 本机模式下 Mock 用不了，这一步显示「登录后可用」，和现在的提示一致。
3. **「更多设置」**，默认收起：路径、延迟、跨域，每项后面一句说明：
   - 路径：「mock 地址最后那段，默认和接口路径一样」；
   - 延迟：「模拟慢接口，单位毫秒」；
   - 跨域：「浏览器里的网页直接调用 mock 地址时要打开」。
4. **「返回数据（示例）」**：现在的示例列表和编辑器，标题改成这个，功能不变。
5. **「按条件返回（高级）」**：现在的期望列表和编辑器。
   - 默认收起，已经有期望时默认展开。
   - 展开后第一行写：「按请求里的参数返回不同的示例，比如『参数 id=1 时返回示例 A，其他情况返回默认示例』。从上到下检查，第一条满足的生效。」
   - 原来那段蓝色的长说明去掉。
6. **右边编辑区没选中任何东西时**：不再显示「左边选一个示例或期望」，改成一句「选一个示例来编辑，或者按左边的三步先把 mock 用起来」。

**不变的：** 示例和期望的增删改、拖拽排序、错误显示、只读成员没有写入口，逻辑都不动，只挪位置、改文字。

**回报：**
- 写清楚「开了但没有示例」时 mock 地址实际返回了什么、最后用的哪句文字；
- 列出在新建示例、删除示例、开关 mock 后三步状态的变化。
