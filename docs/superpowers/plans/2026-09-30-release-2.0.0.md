# 2.0.0 发布收尾计划

> **本项目约定**
> - **只修 bug，不加功能。** 稳定期内，所有提交都要能对应到一个具体的问题。
> - 不写新测试；既有的 `npm test` 必须全部通过。不装浏览器驱动。
> - **只提交，不推送。** 推送和打 tag 都由审阅方来做。只提交自己的文件，不要用 `git add -A`、`commit -a`、`git stash`。

**目标**：把 C 阶段之后新增的功能（HAR 导入、目录设置、流式发送、WebSocket 调试、Postman 脚本、SSE / WebSocket 回放）都补进发布材料，确认安装包干净、能装能跑，然后由用户手工核对，通过后打 `v2.0.0` tag。

**发不发 npm**：打 tag 之后再单独问用户。`npm publish` 是对外发布，不在这份计划的范围内。
