# P2b：把已完成的后端能力补上界面 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **本项目约定**
> - **不写新测试**，也不装浏览器驱动做验证。既有 `npm test` 必须全部通过。
> - 界面效果由用户按每个 Task 末尾的核对清单手工确认。
> - **只提交自己的文件**：`git commit -m ... -- <文件>`。
> - **每个 Task 结束都要执行 `npm run build:web`，把 `lib/web` 和源码放在同一个提交里。** 产物和源码不一致的话，Docker 镜像和 npm 包里带的就是旧页面。

**目标**：P5（智能模板化、mock 期望）、P6（项目成员与角色）、mock 调用日志这三块，后端都已经验收，现在补上对应的界面。另外为 P7a（Cookie、代理）预留一个 Task：等后端交付后再开工。

**依据**：接口契约 [docs/design/2026-09-30-admin-api-v2.md](../../design/2026-09-30-admin-api-v2.md) 的第 8、9、10、11、12 节。

## 全局约束

- **文件范围**：`web/**`、`lib/web/**`；`package.json` 只允许加 `devDependencies`。
- **按角色隐藏或禁用只是体验优化**：真正的权限拦截由服务端的 guard 负责。前端所有写操作仍然要处理 403，把服务端返回的中文错误原样提示出来，不要吞掉。
- **轮询不能漏**：关闭面板、切换项目、离开页面、标签页切到后台时，都要停止轮询。

## 审阅重点

1. **轮询**：
   - 打开日志面板才开始轮询；
   - 关闭面板、组件卸载、切换项目、`document.hidden` 时停止；
   - 切换项目和清空日志之后，`lastSeq` 归零；
   - 不能出现两个定时器同时在跑。
2. **viewer 看到的界面**：以 viewer 身份打开项目时，页面上**找不到任何可以点的写操作入口**。可以发请求、看日志、导出。
3. **模板化必须先确认**：
   - 「智能模板化」一定要先展示替换清单，由用户确认后才生效，不能直接覆盖用户正在编辑的响应体；
   - 服务端返回 `skipped` 时，原样提示，不修改响应体。
4. **期望编辑器的错误提示**：正则不合法、没选示例这类由服务端返回的 400 错误，要把原因显示在出错的那一条期望旁边，不能只弹一个通用的「保存失败」。

### Task 1: 智能模板化

- [ ] **「保存为示例」弹窗**（从响应面板打开）：
  - 新增一个勾选项「智能模板化（把手机号、姓名、时间等换成每次随机的数据）」。只有响应是 JSON 时默认勾选，其他类型不显示这个选项。
  - 勾选状态下点保存：先调用 `/templatize`，然后展示替换清单（表格三列：路径 / 原值 / 占位符）。
  - 用户点「确认保存」，才用模板化后的 body 保存，并且设置 `isTemplate: true`。
  - `skipped` 不为空时，提示原因，并按原文保存。
- [ ] **示例编辑器**：新增「智能模板化」按钮，流程和上面相同，只是确认后改写的是编辑器里的内容。改写后示例进入「未保存」状态，需要用户自己保存。
- [ ] 执行 `npm run build:web`，然后提交。

**核对清单**：录制一个用户列表的响应，勾选智能模板化后保存；打开 mock 地址，每次刷新数据都不一样，但数据结构和字段类型保持不变。

### Task 2: Mock 期望编辑器

放在 Mock 页签里、示例列表的下方。

- [ ] **期望列表**：每一行显示「名称 / 条件摘要 / 返回的示例 / 启用开关」，可以拖动调整顺序（调用 `/expectations/reorder`），也可以删除。
- [ ] **编辑单条期望**：
  - 名称；
  - 返回哪个示例：下拉选择，**只列出本接口的示例**；
  - 条件表格，每一行包含：
    - 位置：query / header / body / path；
    - key；
    - 操作：等于、不等于、包含、正则、存在、不存在、大于、小于；
    - value：操作是「存在」「不存在」时隐藏这一列。
  - 服务端返回的 400 错误，显示在这条期望的旁边（审阅重点第 4 条）。
- [ ] **页签顶部加一行说明**：「从上到下依次检查，第一条满足全部条件的期望生效；都不满足时返回默认示例。响应头 `X-Apiloop-Mock` 会标明命中了哪一条。」
- [ ] 执行 `npm run build:web`，然后提交。

**核对清单**：给一个接口配置「`query` 的 `id` 等于 404 时，返回『不存在』示例」这条期望，访问 `?id=404` 和 `?id=1`，确认两次返回的内容不同。

### Task 3: 项目成员与按角色显示

- [ ] **项目设置页新增「成员」页签**：
  - 成员列表显示用户名、显示名和角色。owner 可以修改其他成员的角色、移除成员。
  - 「添加成员」：先调用 `/users/lookup?q=` 搜索用户，选中后再选角色。
  - 每个人都能看到「退出项目」按钮。如果当前用户是最后一个 owner，服务端会返回 400，把原因原样提示出来。
- [ ] **按 `project.myRole` 控制界面**（`admin` 视同 `owner`）：
  - **viewer 看不到或者不能点的**：
    - 目录树右键菜单里所有会修改数据的项；
    - 「新建接口」「新建目录」；
    - 标签页的保存按钮和 `Ctrl+S`，按下时提示「只读」；
    - Mock 页签里所有编辑控件；
    - 环境管理里的编辑操作；
    - 导入对话框里「导入到当前项目」这个选项；
    - 项目设置里修改变量和鉴权的控件；
    - 清空历史。
  - **只有 owner 可以操作的**：修改项目名称和标识、删除项目、管理成员。
  - **viewer 仍然可以做的**：发请求、查看全部内容、导出、查看 mock 日志。
- [ ] **切换到 viewer 项目时，已经打开的标签页也要切换成只读状态。**
- [ ] 执行 `npm run build:web`，然后提交。

**核对清单**：用 admin 建一个项目，添加一个 viewer 成员；用这个 viewer 登录后，把所有页面点一遍，确认找不到任何写操作的入口。

### Task 4: Mock 调用日志面板

- [ ] **入口**：工作台底部的状态条或顶栏放一个「Mock 日志」按钮，点击后打开一个抽屉。
- [ ] **列表**：每行显示「时间 / 方法 / URL / 命中情况 / 状态码 / 耗时」，新记录追加在最上面。「命中情况」的显示方式：
  - 命中默认示例：显示接口名；
  - 命中期望：显示「接口名 · 期望名」；
  - 没有命中：用红色显示「未匹配」。
- [ ] **点击一行**：展开查看请求头（凭据部分服务端已经打码）、请求体预览和响应预览。如果命中了某个接口，提供「打开接口」按钮，打开这个接口的标签页。
- [ ] **轮询**：每 2 秒用 `after=lastSeq` 拉取一次新记录，行为按审阅重点第 1 条执行。提供「暂停 / 继续」和「清空」按钮，清空只对 editor 及以上角色显示。
- [ ] **空状态**：没有记录时，提示文案里带上当前项目的 mock 地址前缀，例如「访问 `http://localhost:8080/mock/<slug>/...` 后，记录会出现在这里」。
- [ ] 执行 `npm run build:web`，然后提交。

### Task 5: Cookie 与代理（等 session1 的 P7a 交付后再开工）

- [ ] **Cookie 管理弹窗**：从请求编辑器的工具栏打开。列表按域名分组，显示每个 cookie 的名称、值（默认遮住，可以点击查看）、过期时间和标记（Secure / HttpOnly）。可以删除单个 cookie、清空某个域名的全部 cookie、清空全部，也可以手动添加。页面上要注明：这些 cookie 只属于你自己，项目里的其他成员看不到。
- [ ] **请求设置**：在请求编辑器里增加一个「设置」页签，里面放两个开关：「自动管理 Cookie」和「使用系统代理」，分别对应 `/send` 的 `options.cookies` 和 `options.proxy`，默认都是开启。
- [ ] **响应面板**：`result.proxy` 不为空时，显示「经由代理 xxx」；错误码 `PROXY` 要有对应的中文说明。
- [ ] **系统设置页**（只有 admin 能看到入口）：代理设置的表单，包括启用开关、http 代理地址、https 代理地址、不走代理的地址列表。密码在输入框里显示为 `***`，不修改就原样提交回去。
- [ ] 执行 `npm run build:web`，然后提交。
