# 目录设置审阅意见

## F2（a2674d5）：通过

- **鉴权来源的计算**：`utils/auth.js` 的规则和服务端 `inheritAuth` 一致：null 和 `inherit` 都跳过，`noauth` 算作找到。
  - 接口标签页从「接口所在的目录」开始找；
  - 目录标签页从**父目录**开始找，不把自己算进去。这一点是对的。
- **目录链**：`folderChain()` 只维护「从内到外」这一种顺序，有环的时候最多走 64 层就停下。服务端（session1 的 F1 草稿）只维护「从外到内」，调用方需要反过来时自己倒序。两边各自只维护一种顺序，不会出现一边写反的情况。
- **`Ctrl+S`**：是全局的键盘监听，但 `WorkbenchView` 只挂载当前激活的那一个标签页（`v-if` 加 `:key`），所以不会出现一次保存多个目录的情况。
- **只读**：
  - viewer 在目录上右键，只弹出「目录设置」一项，打开后所有控件都是禁用的；
  - viewer 在接口上右键，仍然不弹菜单；
  - 快捷键会提示「只读」。
- **点击整行展开**：加了 `expand-on-click`。你在实现层面核对过，选中和展开发生在同一处点击处理里，空目录不会切换，右键不会连带折叠。
- **没有覆盖别人的改动**：我之前提交的工具栏展开 / 收起切换（612dca3）和下拉样式修复（badf20c）都还在。
- **产物与源码一致**：用 a2674d5 的干净副本重新构建，得到的 `index-3eAQoIZe.js` / `index-BInX84Wk.css` 和提交的完全相同。`npm test` 71/71。
- **体积**：JS 经 gzip 压缩后增加 1.6KB，没有引入新组件。
