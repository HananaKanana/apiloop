## 结论：通过，没有必修项

- **审阅重点 1（未保存修改）**：
  - 标签页是否「未保存」，是拿当前的 spec 和保存时的快照比较得出的，不靠手工置位，所以不会漏标。
  - 关闭标签页、切换项目（`ProjectSwitcher` 检查 `hasDirty`）、刷新页面（`beforeunload`），三种情况都会拦截提示。
- **审阅重点 2（大响应、二进制）**：
  - JSON 大小超过 1MB 时不做格式化，直接显示原文，并给出提示。
  - base64 编码的图片用 `<img>` 显示；即使是带脚本的 SVG，放在 `<img>` 里也不会执行。
  - 其他二进制内容只显示大小，并提供下载。
- **审阅重点 3（HTML 预览）**：用 `<iframe sandbox="" :srcdoc>` 渲染；全仓库搜索确认没有使用 `v-html` 或 `innerHTML`。
- **审阅重点 5（切换项目）**：当前项目 id 保存在 localStorage。如果这个项目已经不存在，`ensureCurrent` 会退回到项目列表里的第一个；环境选择按项目分别记住。
- **登录跳转**：`next` 参数只接受 `#/` 开头的值，并且只交给应用内的 router 处理，不会跳到外站。
